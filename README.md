## Como ler os estágios

- **Disponível:** há uma versão publicada e identificável para uso no escopo divulgado.
- **Piloto ou demonstração assistida:** uso acompanhado e limitado; ainda não representa venda aberta.
- **Em desenvolvimento:** existe código no checkout, sem afirmar que ele está no instalador ou serviço de produção.
- **Experimental:** protótipo de engenharia com gates ainda pendentes.

Cada página separa o que foi observado do que ainda precisa de validação. As datas são importantes: um relatório de infraestrutura ou uma prova de laboratório é uma fotografia daquele momento, não um SLA nem uma garantia permanente.

## Limite de publicação

Este repositório contém apenas material público aprovado. Não inclua código-fonte protegido, hashes de registro do INPI, chaves, certificados privados, endereços internos, dados de clientes, relatórios administrativos, telemetria real ou o livro integral. O livro integral permanece reservado; aqui há somente metadados bibliográficos e links para as demonstrações públicas.
